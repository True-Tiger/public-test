# 전기차 고전압 배터리 시스템

구동 배터리는 여러 셀과 모듈로 구성되며, 배터리 관리 시스템(BMS)이 셀 전압·온도·충전 상태를 감시한다. 팩 구성과 전압 범위는 차종마다 다르다.

## 주요 구성
- 셀·모듈·팩: 전기에너지를 저장하는 단위 구조
- BMS: 셀 상태 감시, 균형 조정, 충전·방전 제한과 보호
- 인버터: 배터리의 직류와 모터가 사용하는 교류 사이의 전력 변환을 제어
- 열관리: 배터리 온도를 관리해 성능과 수명, 안전을 지원

## 충전 상태와 열화
충전 상태(SOC)는 남은 전기에너지의 추정 비율이다. 배터리 열화는 사용 시간, 온도, 충전 습관과 운행 조건의 영향을 받는다. 정확한 사용 한계와 관리 방법은 제조사 안내를 따른다.

## 안전
고전압 부품과 주황색 고전압 케이블은 감전 위험이 있다. 사고·침수·손상 차량의 고전압 계통은 직접 만지지 말고 자격을 갖춘 정비 인력에게 맡긴다.
